# 🐢 Python Turtle Animation – Animated Spiral Art

## 📌 Project Overview

Python Turtle Animation is a beginner-friendly graphics project that creates colorful spiral art using Python's built-in Turtle graphics library.

The project demonstrates how Python loops, functions from the Turtle module, color generation, and geometric calculations can be used to create visual animations.

## ✨ Features

- 🎨 Colorful rainbow spiral animation
- 🐢 Automated drawing using Python Turtle
- 🌈 Dynamic color generation using the `colorsys` module
- 🔄 Geometric patterns created using loops and turning angles
- 🖥️ Interactive graphics window
- 🧑‍💻 Beginner-friendly Python project

## 🛠️ Technologies Used

- **Language:** Python
- **Graphics:** Turtle
- **Color Generation:** colorsys
- **Editor:** Visual Studio Code or any Python-compatible editor

## 📋 Prerequisites

- Python 3 installed on your computer
- Tkinter support available in your Python installation
- Git (optional, for version control)

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-turtle-animation.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-turtle-animation
   ```

3. Run the Python program:

   ```bash
   python main.py
   ```

4. Watch the colorful spiral animation appear in the Turtle graphics window.

5. Click inside the window to close it after the animation finishes.
